# 012S World Search

一款使用原生 HTML、CSS、JavaScript 製作的產品名稱尋字小遊戲。玩家會在 5 × 5 字母棋盤中，逐格點擊相鄰字母，找出每局隨機抽出的 4 個 012S 產品名稱。

## 遊戲流程

網站使用單一 `index.html`，由 JavaScript 控制三個狀態：

1. `HOME`：顯示遊戲介紹、簡單模式與開始遊戲按鈕。此時不會預先生成棋盤。
2. `PLAYING`：按下開始後才抽取產品、生成棋盤並初始化遊戲狀態。
3. `COMPLETED`：找完 4 個產品後保留棋盤與螢光標記，顯示「再玩一次」和「回到首頁」。

「再玩一次」會維持簡單模式並直接生成新的一局；「回到首頁」會清除本局進度。

## 遊戲玩法

- 每局從產品資料中隨機抽取 4 個不同產品。
- 依序點擊字母，不使用拖曳。
- 下一格必須和上一格八方向相鄰：上、下、左、右與四個斜角方向。
- 相鄰判斷公式為 `max(abs(r2 - r), abs(c2 - c)) === 1`。
- 同一個單字的搜尋路徑不能重複使用同一格。
- 不同單字可以共用棋盤格，只要共用格的字母相同。
- 目前輸入必須是至少一個尚未完成產品的前綴；不合法時會顯示短暫錯誤回饋並重置本次選取。
- 找到產品後，路徑會保留淡黃色螢光標記，提示詞短暫高亮後淡出。

## 產品資料與新增方式

所有產品資料都集中在 `products.js`，採用 Array of Objects：

```js
window.PRODUCTS = [
  {
    name: "PPT",
    url: "",
    description: ""
  }
];
```

新增產品時，只要在 `products.js` 的陣列中加入相同格式的物件即可。`url` 與 `description` 已預留給未來的產品官網連結與介紹；遊戲核心不需要跟著修改。

## 棋盤生成方式

1. 先隨機抽出本局 4 個產品。
2. 為每個產品搜尋八方向相鄰的自我避免路徑。
3. 單一產品路徑使用 `Set` 確保不重複格子。
4. 放置時允許不同產品共用字母相同的格子。
5. 若後續產品無法放入，會回溯並嘗試其他路徑；整個生成流程也有自動重試機制。
6. 全部產品成功放入後，才以 A–Z 隨機字母填滿剩餘空格。
7. 生成結果同時保留每個產品的實際合法路徑，方便後續擴充或除錯。

## 檔案結構

```text
012S-world-search/
├── index.html   # 單頁 HTML 結構與 HOME / PLAYING / COMPLETED 畫面容器
├── style.css    # 視覺、互動狀態、動畫與桌面／手機響應式設計
├── products.js  # 所有產品的 name、url、description 資料
├── board.js     # 棋盤生成、產品路徑放置、回溯與隨機字母填充
├── game.js      # 狀態管理、抽取產品、點擊規則、成功／失敗與流程切換
├── ui.js        # 畫面切換、棋盤渲染、事件綁定、提示與視覺回饋
└── README.md    # 專案說明
```

## 執行方式

不需要安裝套件，也不需要建置：

1. 下載或開啟專案資料夾。
2. 直接以瀏覽器開啟 `index.html`。
3. 在首頁選擇簡單模式並按下「開始遊戲」。

## 第一版功能

- 5 × 5 簡單模式棋盤
- 每局隨機 4 個產品
- 合法路徑生成與失敗自動重試
- 八方向點擊與單一路徑不可重複格判定
- 尚未完成產品的前綴判定
- 當前選取、錯誤、找到產品與完成狀態的視覺回饋
- 保留完成後棋盤
- 再玩一次與回到首頁
- 桌面、平板、手機響應式介面
- 鍵盤焦點與螢幕閱讀器基本支援
